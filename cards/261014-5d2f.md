Открыть: npm run board → http://localhost:5199
Колонки: TODO, BACKLOG, Manual test, Гриша/Леша/Даша (в работе у человека — исполнитель ставится автоматически), Done.
Перетаскивайте карточки, кликайте для редактирования.
Карточки живут в ветке board (папка .board/), код не затрагивается.
«Синхронизировать» = commit → pull --rebase → push ветки board.
Можно попросить Claude: «создай задачу…», «перенеси … в Done».
