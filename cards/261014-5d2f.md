Онлайн: https://youngwprota.github.io/WorldOfWarcry-Web/board.html
Смотреть может кто угодно. Редактировать: «Войти для редактирования» → свой fine-grained GitHub-токен (только этот репозиторий, Contents: Read and write). Правки сразу коммитятся в ветку board.

Локально: npm run board → http://localhost:5199 (кнопка «Синхронизировать» = commit/pull/push только ветки board).
CLI: npm run task -- list | add | move | assign | done | sync

Колонки Гриша/Леша/Даша = в работе у человека, исполнитель ставится автоматически.
Можно попросить Claude: «создай задачу…», «перенеси … в Done».
