## Важный контекст
- Сим: `npm run sim -- --runs 20 [--log] [--mobs] [--faction orc]` ≈ 4 с на 20 прогонов. Карта — 1D-тропа (s, отступ),
  бот жадный по ценности/время, бой тиками 0,05 с; оценки кешируются до +3% силы/HP или смены экипировки.
- База (до правок, 20 прогонов): люди меч — Атаман 16:16, Смерть 18:01; орки топор — 38:24 / 41:09.
  Мини-бонус вожака hp +500 (= ×3 HP разом), молот r2 с Атамана делает кладбище тривиальным.
- Золота и заточки в игре нет (убраны); прогресс = сферы, бонусы мини-боссов, дроп элиток/боссов, Горнило.
