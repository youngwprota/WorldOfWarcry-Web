# Баланс после новых оружий и карты + симулятор
Ветка: feat/balance · Статус: готово к проверке

## Цель
Атаман проходим к ~10-й минуте, Смерть — через ~20 минут после него (~30:00); бои вдвое длиннее;
крутки Горнила выпадают с мобов (~1 за 5 мин). `npm run sim` за секунды прогоняет «бота» по карте и
показывает рост статов и момент, когда каждый босс становится проходимым.

## Решения
- Симулятор — модель в node, не настоящая игра (ответ). Формулы боя выносим из game.ts
  в src/balance.ts (чистый TS); их используют и игра, и симулятор, чтобы числа не расходились.
- `npm run sim -- [--faction orc] [--weapon axe] [--runs 20] [--skill 0.7] [--until 40]`: esbuild (из vite)
  собирает tools/sim.ts в .sim/ и запускает в node. Вывод: таблица
  по минутам (зона, сила/HP/реген, предметы, крутки, TTK/TTD боссов), строка «босс побеждён в мм:сс»
  (медиана, p10–p90 по прогонам) и TTK/урон за бой для каждого моба.
- Карта в симе: спавны по island.ts тем же правилом, что world.mobsAlong, плюс заряды и пропсы; ходьба = путь / скорость (допущение).
- Бот: идёт по тропе и бьёт живых мобов и пропсы; при HP < 35% возвращается в лагерь лечиться; к боссу
  идёт, если пробный бой в симе выигран. Навык игрока (`skill`): доля увёрнутых слэмов и время,
  когда герой реально бьёт (uptime). По умолчанию «средний игрок»: 0,6 уворотов, 0,8 uptime (допущение).
- Бой в симе считается тиками по 0,05 с: замахи по aps, комбо каждым N-м ударом, резисты, броня,
  щит людей, жажда крови орков, реген, спецудары босса по кулдаунам из BossDef. Особые механики
  оружий (стаки, притяжение, орбита, казнь, звон, щит, пары с мечом) заданы множителями DPS
  и сверены с числами стенда из new-weapons/handoff.md (допущение).
- Крутки (ответ: с мобов, ~1 за 5 мин): `pulls` в сейве (по умолч. 0), шансы по рангу в `GACHA.token`
  (обычный — малый, элитка/мини — выше, босс — всегда). Начисляется за убийство с всплывающим «+1 крутка»,
  на кнопке Горнила счётчик, при 0 «Ковать» неактивна. Сим берёт ожидаемый дроп с круток (допущение).
- Бои ×2 (ответ): моб 6–10 ударов, элитка ~20 с, босс ~1,5–2 мин в момент, когда его можно пройти.
  HP растёт относительно урона героя, урон мобов подбираем так, чтобы бои оставались опасными.
- Критерий «проходим»: бот среднего навыка выигрывает ≥ 50% прогонов. Атаман — 9–11 мин, раньше 8 — нет.
  Смерть — 28–32 мин. Обе фракции со стартовым оружием; остальные оружия отличаются не больше ±25% (допущение).
- Старые сейвы не мигрируем, для проверки сброс в ⚙ (допущение).

## Шаги
- [x] 1. src/balance.ts: урон удара, множитель силы, heroDps по резистам, входящий урон с бронёй и щитом —
      из game.ts без изменений поведения; Game вызывает их.
- [x] 2. tools/sim.ts + `npm run sim`: модель карты (спавны, заряды, пропсы, ходьба), лут (сферы, бонусы мини,
      дроп элиток), бой тиками (дуэль и группа), бот и правило попытки на босса, отчёт по минутам и итог.
- [x] 3. Множители особых оружий и пар в симе; сверка с цифрами стенда. Базовый прогон на текущих
      числах (обе фракции, все оружия) → таблица в handoff.md.
- [x] 4. Крутки: `pulls` в сейве, GACHA.token, начисление за убийство, счётчик и блокировка «Ковать»,
      дебаг «+5 круток»; сим учитывает крутки.
- [x] 5. Бои ×2: HP мобов, элиток, мини и боссов против урона героя; урон мобов — под опасность. Сим показывает
      TTK в целевых рамках.
- [x] 6. Темп: сферы, награды, DEPTH, заряды, HP/урон боссов, шансы круток → Атаман 9–11 мин, Смерть 28–32,
      ~1 крутка за 5 мин, обе фракции; разброс по оружиям ≤ ±25%.
- [x] 7. README (крутки, `npm run sim`), итоговая таблица в handoff.md.

## Проверка
- tsc без ошибок, `npm run build` собирается, `npm run sim` за < 10 с печатает отчёт
- в браузере (телефон и ПК): сброс сейва → Горнило 0, «Ковать» неактивна; за 10 мин 1–3 крутки;
  моб — 6–10 ударов; к ~10-й минуте Атаман жёлтый, бой ~1,5–2 мин; «Лог баланса» сверяем с симом.
