# Хотфикс: UI мельче на телефоне
Ветка: hotfix/mobile-ui-size · Статус: готово к проверке

## Цель
На обычном телефоне (Android Chrome, ~393×730 видимой области) HUD занимает слишком много экрана. Нужно сделать его примерно
на 15% мельче, чтобы игровое поле было видно лучше.

## Решения
- Меняем только число `UI_BASE` в src/config.ts: 400×720 → 470×840. Механизм масштаба (`UI.fit`, `--ui`) уже
  есть: s = min(1, w / UI_BASE.w, h / UI_BASE.h). Сейчас на 393×730 получается s ≈ 0.98, то есть масштаба
  почти нет, отсюда «большевато».
- Новые s: 393×730 → 0.84; 412×860 → 0.88; 360×740 → 0.77; десктоп с колонкой ≥470 px шириной → 1 (без изменений).
  Пропорции HUD к экрану становятся одинаковыми на всех телефонах (допущение: на 15% мельче — достаточно,
  число подбираем на шаге 2 по скриншотам).
- Виртуальный экран становится шире (470), поэтому HUD-блоки сильнее расходятся к краям. Шторки и сетки
  растягиваются на 100%. Это проверяем, переписывать вёрстку не собираемся.

## Проверка
- `npm run build` без ошибок
- в браузере (npm run dev) на 393×730: HUD заметно мельче, чем на скриншоте пользователя, текст читается,
  ничего не налезает; сумка, окно героя и таланты влезают; на десктопе вид как раньше.
- на телефоне: кнопки «Герой» и «Сумка» и слоты нижней полосы всё ещё легко нажимаются пальцем (≥ ~44 px на экране).
