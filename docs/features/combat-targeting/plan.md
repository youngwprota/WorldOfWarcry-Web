# Автоатака: цель не залипает вне удара
Ветка: fix/combat-targeting (GitButler, git видит gitbutler/workspace) · Статус: готово к проверке

## Цель
Герой бьёт то, что у него в зоне удара: стоя у могилы, он бьёт её, а не держит цель (моба или
другую могилу) в 3–4 м, до которой меч не достаёт. Удар по предмету виден цифрой урона.

## Решения
- Причина: цель держится до `range + acquireExtra + radius + 1`, а удар — только при
  `d - radius ≤ range + 0.35`; новая цель ищется лишь когда старой нет (game.ts ~593–629).
- Одна функция «в зоне удара» (`inStrike(u)`: `d - radius ≤ w.range + 0.35`) для выбора цели,
  проверки перед замахом и inShape — пороги больше не расходятся (убирает и полосу 2.65–2.7 м).
- Каждый кадр: если текущая цель не в зоне удара — ищем лучшую цель в зоне удара (моб важнее
  предмета, затем ближайший); нашли — переключаемся. Не нашли — старая цель остаётся только для
  разворота, пока она в прежнем радиусе удержания.
- Если текущая цель — предмет, а в зоне удара появился моб, переключаемся на моба (моб важнее,
  как и при выборе). (допущение)
- Без проверки видимости (line of sight) — отдельная задача, если жалобы останутся.
- Цифра над предметом при ударе: `-1`, `-0.5`, `-1.5`, `-3` (финишер), цвет как у мобов
  (weak/resist) через тот же fx.spawn. (допущение: дробные показываем с одним знаком)
- Пролог (src/prologue.ts:472) не трогаем: там только призраки, предметов нет.

## Проверка
- tsc без ошибок, `npm run build` собирается
- в браузере (`npm run dev`, телефон и ПК), кладбище:
  - ударить могилу A, отойти к соседней B (2–4 м) — герой сразу бьёт B;
  - моб откинут/уходит на 3–4 м, рядом могила — герой бьёт могилу, моб вернулся в удар — бьёт моба;
  - в лагере у края, моб снаружи бродит рядом — лагерные предметы бьются;
  - при ударе по могиле видны цифры -0.5 (меч/топор) и -1.5 (молот).
