# Воин: слот оружия + классовый слот (щиты)
Ветка: warrior · Статус: готово к проверке

## Цель
Вместо двух рук: слот 1 — оружие, слот 2 — предмет класса. Воин: меч / топор / молот / древковое
в слоте оружия и один из трёх щитов во втором слоте. Набор слотов задаётся классом из src/party.ts.

## Решения
- Экзотика (кинжалы, жнец, коса, сковорода, скрытый клинок) и бонусы пар с мечом удаляются совсем
  (offhand.ts, SWORD_PAIRS, DUAL, поля stack/pull/orbit/ring/assassin) — так решил пользователь.
- `save.weapons` остаётся кортежем `[оружие, классовый слот]` — меньше правок в game/ui/inventory/sim.
- Щиты — по-прежнему WEAPONS с `guard`, сами не бьют никогда (убрать «два щита бьют щитом» и `bash`/COMBOS.shield).
- 3 щита (id `shield_tower` / `shield_buckler` / `shield_spiked`): Башенный −30% урона, редкие контратаки;
  Баклер −10%, частые контратаки; Шипастый −15% и `guard.reflect` — доля полученного урона бьёт атакующего.
  Модель у всех `shield` (допущение), иконки — тинтом.
- Древковое = переделанная нагамаки, id `polearm` (модель `nagamaki`): урон ниже меча, медленно, дальность высокая;
  серия по доске: укол → укол (только по цели, `single`) → прокрут 360° (финишер `spin`), цепь не рвётся (`cycle`).
- В ClassDef (party.ts): `weapons: string[]`, `off: string[]`, `offName`. Воин: 4 оружия + 3 щита, «Щит».
  Охотник/маг — пустые списки (допущение): их кнопки переключают, но экипировку пока не трогаем.
- Экипировка без выбора руки: предмет из `off` класса → слот 2, из `weapons` → слот 1, чужой — «Не для воина».
  Слот оружия не бывает пустым: только замена, «Снять» есть лишь у щита (допущение).
- Миграция сейва: удалённые defs выпадают через `known()`; `nagamaki` → `polearm`, `shield` → `shield_tower`;
  щит в слоте 1 / оружие в слоте 2 — поменять местами; второе оружие — в сумку.
- Меч/топор/молот по числам не трогаем (сплеши с доски — в балансе отдельно).
