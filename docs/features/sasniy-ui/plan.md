# Крутой UI в стиле Butcher Hero
Ветка: feat/sasniy-ui · Статус: готово к проверке

## Цель
Весь интерфейс получает «мультяшно-мобильный» вид Butcher Hero: деревянные панели, жирный шрифт с обводкой,
«конфетные» 3D-кнопки, ячейки предметов по цвету редкости. Механика игры не меняется, меняется только UI.

## Решения
- Переносим только то, что есть в нашей механике. Самоцветы, VIP, эволюция/копии, почта, звёзды и закреплённые слоты — нет.
- Шрифт Rubik 800/900 (кириллица, «жирный мобильный» вид) через пакет @fontsource/rubik: его собирает Vite, работает без CDN и на Pages (допущение).
- Палитра в токенах `:root`: дерево #6b4a33/#8a5f40, крем #f3e3c8, кнопки: жёлтая (главное действие), красная (✕), фиолетовая, зелёная, серая. Текст с обводкой через `-webkit-text-stroke` и `paint-order`.
- Ячейка предмета: фон-градиент по редкости (серый/синий/фиолетовый/оранжевый), значок типа урона в левом верхнем углу, уровень/заточка числом в правом нижнем. Один хелпер `cellHtml()` используется везде.
- Иконки: SVG-силуэты в `src/icons.ts` (броня по слотам, шестерёнка, герой, сумка, череп, замок, монета, сердце, песочные часы) вместо эмодзи: эмодзи нельзя перекрасить и обвести.
- Числа в стиле «3.05K»: хелпер `fmtK()`.
- HUD: снизу полоса «Экипировано» (2 оружия, активное крупнее, тап = смена) по образцу 4-го скрина. Справа над ней — большие квадратные кнопки Герой/Сумка (как магазин и сундук). Слева — виджет босса (череп + «ГОТОВО!» или таймер).
- Под миникартой — название зоны с обводкой (как «Луговые земли - 1»).
- Сумка становится нижней шторкой «ИНВЕНТАРЬ» (скрин 1): вкладки-фильтры, разделители секций, полоса «Экипировано» внизу.
- Карточка предмета (скрин 3): ячейка-иконка, плашки редкости и типа, строка «Урон 120 › 150» в сравнении с надетым, блок способности. Для оружия способность — добивание комбо из `COMBOS`, для брони — бонус-стат.
- Окно героя: сверху карточка «Характеристики» (крупные DPS / HP / РЕГЕН + чипы 3×2), ниже 3D-кукла со слотами в новом стиле.
- Кузнец оформлен как магазин (скрин 2): лента-заголовок секции, карточки с оранжевой кнопкой цены в золоте (допущение).
- DOM HUD обновляется по-прежнему только при изменении состояния. Таймер босса — не чаще раза в секунду.

## Проверка
- `npm run build` без ошибок
- в браузере (npm run dev): HUD как на 4-м скрине (полоса оружия снизу, кнопки справа, виджет босса слева, зона под картой); сумка выезжает шторкой, фильтры работают; карточка показывает сравнение и надевает предмет; окно героя и кузнец в новом стиле; смена оружия тапом и Q работает
- на телефоне (ширина 360–390): ничего не обрезается, кнопки ≥44px, стик не перехватывает тапы по UI, FPS не просел
