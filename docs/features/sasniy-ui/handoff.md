## Решения по ходу
- Шрифт: @fontsource/rubik 600/700/900 импортируется в main.ts. Обводка текста — переменные --stroke / --stroke-s (text-shadow), а не -webkit-text-stroke: тот съедает тонкие буквы.
- Кнопки .btn: цвет через --c1/--c2, варианты primary/red/purple/green/blue. Отдельная красная .xbtn для ✕. fmtK() лежит в icons.ts.
- Иконки: icon(id, color, size, cls) в icons.ts. ARMOR_SLOTS.icon теперь id иконки ('head'…), а не эмодзи. cellHtml() и itemIconId() лежат в items.ts (items импортирует icons, обратного импорта нет). Цвет редкости ячейки задают классы .r0–.r3.
- HUD: нижняя полоса #equipbar = #weapons (2 оружия, тап по неактивному = смена) + #armorbar (6 слотов брони, тап открывает окно героя через ui.onArmor). ui.weapons() теперь принимает и equip. Кнопки Герой/Сумка — #side-btns справа над полосой.
- Виджет босса: HudState.bosses {name, left} (left — целые секунды, поэтому ключ JSON меняется раз в секунду). Тап по виджету открывает карту.

## Грабли и что не сработало
- bash heredoc с python-кодом, где много кавычек и скобок, ломался (unexpected EOF). Большие правки лучше писать скриптом в scratchpad и запускать файлом.
- Скриншоты в Chrome: окно браузера широкое, приложение рисуется колонкой 9:16 по центру; resize_window на скриншот не влияет.
