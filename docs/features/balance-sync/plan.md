# Баланс-тулза догоняет игру: дальние земли, пачки, все боссы
Ветка: feat/balance-sync · Статус: готово к проверке

## Цель
`npm run sim` и balance.html снова отражают игру: бот после Смерти идёт через ворота по дальним землям
(Перевал → Холмы → Роща → Болото → Дюны), фармит их и бьёт всех 7 боссов; карта — весь остров.

## Что сейчас не так (сверка)
- Сим знает только лес и кладбище: нет PEAKS/GROVE/SWAMP/DUNES_SPAWNERS, SPAWNERS.hills, HILLS_*, LAND_ELITES,
  мини дальних земель (+MINI_PAIR_OF), 5 боссов, ZONE_TIER (×HP/урон), ворот GATES.
- Резисты: игра даёт мобу профиль зоны, где он стоит (Game.zoneDef: zoneResist, alt через одного на Перевале,
  boss-профиль боссу), сим берёт MobDef.resist как есть.
- Пачки (link 'social', joinPack: CEMETERY_PACKS, HILLS_PACKS, стража) — в симе всё один на один.
- Кладбище: спецмобы стоят на пинах CEMETERY_AREAS (деревня, часовня), в симе — без пинов.
  Стража: в игре пара у точки + третий одиночка в пустом лесу, в симе все трое у точки.
- Открытие зон: сим открывает кладбище после любого босса, а не по `boss.unlocks`; киты героя только forest/cemetery.
- Редактор конфига: нет групп STAVES, ZONE_FOES, PET_RARITY, FACTIONS.

## Решения
- Бот идёт дальше (ответ): зона открывается, когда убит босс, чей `unlocks` ведёт в неё (GATES from→to).
- Боссы дальних земель — общая модель (ответ): слэм/погоня из BossDef × ZONE_TIER; у Сестёр второй враг —
  BOSS_PARTNERS × тир. Особые приёмы китов src/bosses не моделируем, сверяем по логу из игры.
- Spot получает `zone`; вне тропы — точные x/z. Ходьба между зонами: прямая внутри зоны + цепочка ворот (BFS по GATES).
- Точки: ручные (packs/elites/LAND_BOSSES/LAND_ELITES/баннеры) — точно; случайные разбросы world.ts
  (ассасины, звери, деревья, львы, лагеря рощи/болота/дюн) — равномерно вдоль LAND_TRAILS зоны, `approx` на карте (допущение).
- Числа моба как в Game.addMob: zoneDef-резисты + ZONE_TIER на HP и урон, награда без тира — одна функция в simcore.
- Пачка = один бой с несколькими врагами: бьют все живые, герой валит по одному (fight принимает список врагов).
- `--until` по умолчанию 90 мин, чтобы бот успевал до Дюн (допущение). Поведение мобов (LEASH, засады) — вне.
