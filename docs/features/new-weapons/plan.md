# Новые типы оружия: кинжалы, жнец, нагамаки, коса, сковорода, скрытый клинок, щит + вторая рука
Ветка: feat/new-weapons · Статус: готово к проверке

## Цель
Две руки, любые два оружия; меч в паре даёт уникальный бонус, щит — контратаки; 4 новых оружия; баланс сборок.

## Решения
- Зачарований нет (решение пользователя): «прок эффектов» → свои механики оружия.
- Слоты: weapons[0] правая, weapons[1] левая, любые оружия (решение пользователя), можно пусто. Свап Q убран.
- Каждая рука — свой таймер атаки и своё комбо; в паре урон каждой руки ×0.6 (две руки ≈ ×1.2 к одной), бонус
  меча/щита сверху (допущение). Щит сам не бьёт: −15 % входящего урона и контратаки оружием другой руки;
  два щита — контратака ударом щита; два одинаковых — без бонуса пары (допущение).
- Сборки и роли (баланс шага 14): одна цель — кинжалы/клинок + меч; толпа — жнец/нагамаки/молот/коса + меч;
  танк — щит + любое; фан — сковорода + нож. Цель: DPS сборки в своей роли в пределах ±15 % от эталона
  (топор+меч), вне роли — заметно слабее. Замер через balancelog/дебаг (одиночный босс, толпа из 6).
- Новые оружия (числа — допущения, правятся на шаге 14):
  - нагамаки: цикл ударов справа-налево → слева-направо (arc 200°, ×0.7) → укол (узко, range 3.2, ×2.2);
  - коса (по доске): бросок, коса 3 с кружит вокруг героя (r 3 м) и бьёт всех на пути, низкий AS;
  - сковорода: круг 1.6 м перед героем, удар сверху, дробящий, 60 % шанс оглушить, 30 % «звон» ×2 урона;
  - скрытый клинок: только ближайший враг, AS 0.45, ×3.2 урона, всегда оглушает, по обычным мобам
    < 25 % HP — казнь; сочная анимация: рывок, хитстоп, slow-mo 0.15 с, приближение камеры.
- Щит: шанс контратаки от ранга врага — обычный 20 %, элитка 30 %, мини-босс 40 %, босс 50 %. Основное
  оружие бьёт в сторону врага со всеми эффектами (стаки, стягивание…), кулдаун 0.4 с (без петель).
- Бонусы меча во второй руке: кинжалы — удар мечом +8 % AS кинжалов (до +40 %, сброс 2.5 с); жнец — при
  толпе > 7 удар мечом убивает лишних обычных мобов (кд 4 с); коса — попадание 20 % → меч кружит вокруг
  врага 4 с и бьёт, 15 % перекинуться на соседа (≤ 6); топор — +4 % текущего HP (боссы 1 %); молот — меч
  становится серпом, молот без отбрасывания бьёт сильнее к центру, серп 10 % → союзник с серпом/молотом
  на 8 с, серп-союзник 5 % → ещё один (≤ 4); щит — 15 % враг сразу бьёт героя (провокация контратаки);
  нагамаки — случайный 4-й удар: падающий меч, подброс, рывок-вихрь; сковорода — меч → кухонный нож, мобы
  в 6 м убегают 3 с (состояние flee), урон ×0.5, ящики не бьются; клинок — укол мечом, урон +60 %, AS −15 %.
- Анимации процедурные: поверх SwordAttack/AxeAttack поворот костей по ключам + шлейф (допущение).
- Модели: Blender-скрипт tools/blender/weapons.py — нагамаки, коса, щит, сковорода, скрытый клинок, серп,
  кухонный нож. Союзники — уменьшенная модель героя. Перчатки — вне рамок. Источник: гача + дебаг.
