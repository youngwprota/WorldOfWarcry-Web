# Новые типы оружия: кинжалы и жнец
Ветка: feat/new-weapons · Статус: утверждён

## Цель
Два новых оружия со своей механикой: кинжалы (очень быстрые, урон по одной цели растёт с каждым ударом)
и жнец (каждый взмах стягивает врагов в точку перед героем, урон растёт с числом задетых).
Остальные типы (коса, перчатки, нагамаки, щит, сковорода, скрытый нож) пользователь распишет позже.

## Решения
- Меч и топор уже есть (WEAPONS.sword/axe). Сейчас делаем только dagger и reaper, остальные типы — вне рамок.
- Механика задаётся в WeaponDef необязательными полями: `stack?: { add, max, decay }` (кинжалы) и
  `pull?: { radius, ahead, perEnemy, max }` (жнец). heroStrike читает их, без отдельных классов на оружие.
- Кинжалы: slash, single, aps ≈ 2.4, dmgMul ≈ 0.45; каждый удар по мобу +12 % урона по нему, до +120 %,
  стаки сгорают через 2.5 с без ударов. Стаки лежат на Mob (`stacks`, `stackAt`), новый моб начинает с нуля (допущение).
- Жнец: slash, arc 200°, range 2.6, aps ≈ 0.8, dmgMul ≈ 1.1. Перед ударом мобы в радиусе ~5 м получают
  импульс в точку в 1.5 м перед героем (через m.knock, боссов не тянем); урон × (1 + 0.15·(n−1)), до ×2 (допущение).
- Комбо-финишеры: кинжалы «Шквал» (быстрый круг, все стаки ×2), жнец «Жатва» (сильное стягивание + круг) (допущение).
- Анимации: своих клипов нет — кинжалы на SwordAttack (клип ускоряется под period), жнец на AxeAttack (допущение).
- Кинжал один в правой руке; второй в левой — только если attachWeapon легко обобщить на hand_l (допущение).
- Модели: в проекте нет кинжала и косы жнеца → Blender-скрипт tools/blender/weapons.py (как forge_props.py):
  лоу-поли, плоское затенение, UV на палитру proto_human_RTS_color.png, чтобы стиль совпадал с Bitgem.
  Экспорт в public/assets/models/dagger.fbx, reaper.fbx; фракции получают одну модель (допущение).
- Где взять: дроп элиток (по одному элитному мобу на оружие) + кнопка в debug-панели «выдать оружие» (допущение).
- Иконки: новые dagger и reaper в icons.ts и art.ts, в том же стиле.
