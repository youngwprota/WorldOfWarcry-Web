## Решения по ходу
- Влит main (combat-targeting, webgl-contexts): выбор цели — inStrike из main по самой длинной руке (reach()), удары рук — inStrike(t, range + ahead).
- Пары: SWORD_PAIRS в config, Game.pair (offhand.swordPair) обновляется в equipVisual. Клинок+меч: меч сам не бьёт, handMulOf(blade)=1. Топор+меч: руки бьют синхронно.
- Щит рядом с оружием сам не бьёт; один щит или два — бьёт сам (иначе нельзя ломать ящики). Ранг врага — mobRank() (boss/rank/normal).
- Удары: WeaponDef.swing — процедурные (Swinger поверх клипа, кости spine_01/upperarm); левая рука без своего swing — LEFT_SWING по клипу. Клинок перпендикулярен предплечью: «ровный» укол = низкая рука + наклон корпуса.
- Всё в этой ветке; зачарований нет и не делаем; механики можно менять ради баланса сборок (пользователь).
- В двух руках любые оружия (пользователь); бонусы пар — только у меча и щита.
- Модели в FBX (не GLB): тот же путь, что у Bitgem (loadAll + атлас proto_human_RTS_color по имени).
- Палитра: UV на градиентные колонки атласа (u — колонка, v — тень); таблица PALETTE в weapons.py.

- Новые оружия сами попадают в гачу (gacha.ts берёт случайный ключ WEAPONS) — это уже источник.
- resistIcons теперь по типам урона (раньше по оружию — дубли иконок на slash).
- Стаки: Mob.stacks/stackAt/setStacks, бейдж .stk «×N» под HP; сброс в updateMobBars (decay текущего оружия, без кинжалов — сразу).
- Жнец: reapPull в начале замаха (m.knock = 9·force·расстояние, knock гаснет ×(1−9dt) → проходит ~force пути), обычный удар жнеца почти не отбрасывает (0.5), чтобы толпа не разлеталась.
- Дроп: элитка «Тень» (кладбище) → кинжалы r2 вместо меча; босс «Смерть» → жнец r3 вместо молота и держит косу в руке. Debug: секция «Оружие в руку».
- Баланс кинжалов: было ×2 к мечу на полных стаках → dmgMul 0.38, +6%/стак, финишер стаки не удваивает (~+20–30% к мечу после разгона ~4 с).

- Стенд с hp=1e9 врёт для пары топор+меч (% от текущего HP) — на шаге 14 мерить на реальных HP (время убийства).
- Blender: weapons.py -- <preview_dir> [имена] собирает только указанные; numpy-wheel в scratchpad/np. Щит: grip `face` кладёт диск поперёк кулака.
- Левая рука: кости в bind-позе совпадают, но Idle несимметричен → зеркало по X + поворот LEFT_FIX (rig.ts), замерено по Idle.
- Headless Chrome (swiftshader) ~3 fps: игровое время почти стоит → в тестах крутить __game().update(1/30) вручную.
- Системный Blender 4.0 без numpy → FBX-экспорт падает. Скачать wheel numpy 1.26.4 cp312 в scratchpad, PYTHONPATH + --python-use-system-env.
- В атласе красный — колонка u=0.594 (нижняя половина), не 0.719 (там бледно-голубой).
