- Термины: у пользователя «мини-босс со снарягой» = элитка (rank 'elite'), «оранжевый» = микробосс (rank 'mini').
- Решение команды: нижняя полоса делится пополам — левая (оружие + шлем/нагрудник/сапоги, EQUIP_BAR.left в items.ts)
  падает с боссов, правая (перчатки/кольцо/амулет) — из гачи. Пул гачи меняет не эта фича.
- Кучки мобов (после открытия лучника) делает другой человек — не трогать спавн пачками.
