## Грабли и что не сработало
- heredoc с python и кавычками в bash ломается — длинные правки писать .py в scratchpad.
- #hint (тост) при desktop-окне ниже экрана в скриншотах — проверять через DOM.
- Частицы (ambient.ts) прыгали при ходьбе: подъём/снос были uTime × скорость, а скорость смешивается по весам зон под героем. Теперь смещение копится на CPU (uRiseOff/uDriftOff += скорость·dt, dt ≤ 0,1).
- Пользователь: элитки кладбища дают ОБЫЧНЫЙ (rarity 0) сет охотника — шлем, нагрудник, сапоги, лук.
- Разрушаемые (BREAKABLES) переведены с hits на hp: урон по ним = damageFor() как по мобу (резист материала, криты, множитель добивания). HP: куст 40, ящик 60/200, бочка 120, надгробие 500, гроб 900, башня форта 1500 (прикидка, баланс потом). Сим: propTime = hp / heroDps.

## Важный контекст
- Пользователь: кладбище — слабость к луку, резист к мечу. Маг открывается НЕ после Смерти — логику мага не трогать.
- Ветку feat/graveyard-loot создал агент по просьбе пользователя («делай в отдельной ветке»).
- Термины: у пользователя «мини-босс со снарягой» = элитка (rank 'elite'), «оранжевый» = микробосс (rank 'mini').
- Решение команды: нижняя полоса делится пополам — левая (оружие + шлем/нагрудник/сапоги, EQUIP_BAR.left в items.ts)
  падает с боссов, правая (перчатки/кольцо/амулет) — из гачи. Пул гачи меняет не эта фича.
- Кучки мобов (после открытия лучника) делает другой человек — не трогать спавн пачками.
- Броня охотника: ARMOR `hunter_head|chest|arms|legs` (items.ts SETS), лук — WEAPONS.bow, класс hunter в party.ts.
