# Кладбище: дроп боссов, открытие лучника, подзоны
Ветка: feat/graveyard-loot · Статус: готово к проверке

## Цель
Лес — только мечник; Атаман роняет лук и открывает Охотника. На кладбище 4 элитки одевают охотника,
Могильщик (оранжевый) даёт стат, Смерть роняет меч покруче для мечника. Кладбище делится на узнаваемые подзоны.

## Решения
- «Мини-боссы со снарягой» = элитки (`rank: 'elite'`), «оранжевый» = микробосс Могильщик (`rank: 'mini'`, +реген) — так в коде.
- Дроп боссов/элиток кладбища — только левая половина полосы (оружие, шлем, нагрудник, сапоги), кольцо Смерти убираем.
- Атаман: молот → лук (необычный). Смерть: кольцо → меч (эпический). Числа не трогаем (допущение: редкости такие).
- Элитки кладбища: Костяной страж → шлем охотника, Тень → сапоги охотника, новые «Мародёр» → нагрудник охотника,
  «Проклятый стрелок» → лук (оба редкие). Модели — имеющиеся undead_* с `scale`/`tint` (допущение).
- Кладбище слабо к луку и сопротивляется мечу. Меч и лук сейчас оба `slash`, поэтому у лука новый тип урона
  `pierce` («колющий», своя иконка лука и цвет в icons.ts/config.ts). `ZONE_FOES.cemetery`: weak `pierce`, `crush`,
  resist `slash`, `chop` (дробящий и рубящий оставлены как были — допущение). Побочка: на холмах и болоте (weak `slash`)
  лук теряет бонус — ок до баланса.
- Класс открывается воротами: `ClassDef.unlock` = id ворот; охотник — `forest-cemetery` (первое убийство Атамана).
  Новое поле в сейве не нужно — гейты уже сохраняются. Мага не трогаем (пользователь: «пока не трогай»).
- Закрытый класс: кнопки нет в `#party`, клавиша игнорируется; при открытии — тост «Открыт Охотник» и вспышка кнопки.
- Подзоны кладбища — точки (угол/радиус как `pol()` в buildCemetery) в `CEMETERY_AREAS` (config): Заброшенная деревня
  у ворот, Погост (могилы у тропы, как сейчас), Руины часовни, Поле могил (южный тупик), Арена Смерти.
  Элитки и Могильщик стоят пинами в своих подзонах (`CEMETERY_PINS`, как `FOREST_PINS`). При входе — тост с названием.
- Порядок по тропе: деревня — нагрудник, погост — шлем, руины — лук, поле могил — Могильщик, перед ареной — сапоги.
- Кучки мобов не трогаем (делает другой человек), мобы кладбища остаются по одному.

## Проверка
- `npm run build` без ошибок, `npm run sim` отрабатывает
- в браузере: новый герой — одна кнопка класса; дебагом убить Атамана → лук в сумке, появилась кнопка Охотника;
  на кладбище 4 элитки с иконками вещей охотника на карте, Могильщик оранжевый, Смерть роняет эпический меч;
  проход по тропе показывает тосты подзон; деревня и руины видны с тропы
- на телефоне: кнопки классов не съезжают при 1/2/3 кнопках, FPS на кладбище не просел
