# Базовый баланс: кривая силы и бои с боссами
Ветка: feat/boss-fight-balance · Статус: утверждён

## Цель
Предсказуемая кривая: после одного прохода зоны её босс «жёлтый» (бой ~45–60 с, 3–4 пропущенных
слэма = смерть), после второго круга — «зелёный». Обычные мобы опасны группой, но не одиночкой.

## Решения
- Контрольные точки: С0 старт; Л1 — лес зачищен 1 раз; К1 — Л1 + Атаман + кладбище 1 раз. Для каждой
  считаем статы героя (сила, HP, реген, DPS по резистам) вручную, таблица в handoff.md — без скрипта (ответ).
- «Зачищен» = каждый моб зоны убит 1 раз + ~половина разрушаемых; случайный лут не учитываем,
  гарантированный учитываем (молот редкий с Атамана) (допущение).
- TTK босса считаем как в bossColor (чистый DPS, без комбо и промахов): цель 45–60 с на своей точке
  (Л1 — Атаман мечом/топором, К1 — Смерть молотом). Порог цвета (35/80 с) не трогаем.
- Сейчас рост слишком быстрый: сфера силы +2% урона, за лес ≈ +62 силы → Атаман ≈ 23 с («зелёный»).
  Чиним в первую очередь ценой сфер и наградами, HP боссов — во вторую.
- Опасность босса задаём через удар по площади: слэм ≈ 25–30% HP героя на его точке, ближний удар
  ≈ 3–4% HP/с — стоять в мили можно, в красной зоне нельзя.
- Константы боя боссов из bossLogic (кулдауны 6,5/4,2 с, множители 2,2/1,4, радиус 2,3, задержки,
  ×1,2 урона в фазе 2) переезжают в `boss` в MOBS — тюнинг только в config.ts.
- Человек/меч и орк/топор должны попадать в один цвет на каждой точке; пассивки не трогаем.
- Старые сейвы не мигрируем: статы накоплены по старым ценам, для проверки — сброс в ⚙ (допущение).

## Проверка
- `npm run build` без ошибок
- в браузере (npm run dev): сброс сейва → проход леса один раз → имя Атамана жёлтое, бой ~1 мин,
  стоять в красном круге смертельно за 3–4 слэма; повторный круг → имя зелёное. То же для кладбища
  и Смерти с молотом. Обе фракции. Цвет имени и полосы босса проверить на телефоне (вид не меняется).
