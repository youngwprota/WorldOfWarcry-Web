# Концепт гача-предметов
Цифры здесь условные: только характер предмета. Значения подберём в балансе (`npm run sim`).
Правило: у каждого слота своя роль, внутри слота три (и больше) предмета тянут в разные стороны.

## Общие слоты (носит любой класс)
| Слот | Роль | Предмет (люди / орки) | Что даёт | Чем отличается |
|---|---|---|---|---|
| Перчатки | как бьёшь | Рукавицы силы / Кулаки вождя | +Урон | ровная прибавка, всегда полезна |
| | | Перчатки меткости / Хватка следопыта | +Шанс крита | всплески, хорошо с Сферой демона |
| | | Перчатки проворства / Лапы ловкача | +Скорость атаки, % (новый стат `haste`) | лучше с быстрым оружием и горением/заморозкой |
| Кольцо | как двигаешься, особый эффект | Кольцо ветра / Кольцо следопыта (есть) | +Скорость бега | кайт, обход паков |
| | | Кольцо тени / Кольцо сумрака | +Уклонение | против боссов с тяжёлым ударом |
| | | Кольцо крови / Клык крови | вампиризм: % урона в HP (новый стат `leech`) | лечится только в бою, растёт с уроном |
| Амулет | как выживаешь | Амулет родника / Тотем крови (есть) | +Реген, хп/с | долгий бой без лагеря |
| | | Сердце льва / Сердце вепря | +Макс. HP | переживает пик урона |
| | | Оберег / Костяной оберег | +Защита | против толп мелких ударов |

Перчатки больше не часть комплекта класса: на модели и в иконке — перчатки комплекта того класса, кто их
надел, нужного качества (рыцарь/вождь, охотник, маг уже нарисованы по всем качествам).
Кольцо и амулет на модели одинаковые для типа (модель по качеству уже есть), тип видно по значку стата в углу ячейки.

## Предмет класса (второй слот)
**Щит — воин.** Отвечает «как держу удар». Все три снова в игре:
- Башенный — «стена»: сильный блок, редкая контратака.
- Баклер — «дуэлянт»: слабый блок, частая контратака.
- Шипастый — «ёж»: средний блок, отражает часть урона атакующему; лучший в толпе.

**Сфера — маг.** Пассивная аура над плечом, у каждой сферы одно своё качество (так и остаётся):
Яростный клич (обычн., +урон), Благословление бодрости (необычн., +реген), Сфера ветра (редк., +скорость),
Сфера оберега (эпич., +защита), Сфера удачи (легенд., шанс крутки), Сфера демона (миф., крит. урон).

**Питомец — охотник.** Теперь предмет с качеством (урон растёт с качеством, зверь чуть крупнее).
Главное отличие — тип урона (резисты мобов) и манера боя:
| Питомец | Модель | Урон | Манера |
|---|---|---|---|
| Вепрь (есть) | orc_boar | дробящий | ровный, средний темп — база |
| Лютоволк | wild_direwolf | режущий | быстрый, частые слабые укусы |
| Медведь | wild_bear | рубящий | медленный тяжёлый удар лапой по всем рядом (cleave) |
| Лев | wild_lion | колющий | прыжок на цель издалека, первый удар усилен (pounce) |
| Костяной вепрь | undead_boar | магический | как вепрь, но магией — против тех, кто держит физику |

## Баннер Горнила
Легендарка баннера — «Кольцо Короля-лича» (Кольцо крови легендарного качества с именем).
Оружие и броня тела (шлем, нагрудник, сапоги) из гачи больше не падают — они с мобов.
