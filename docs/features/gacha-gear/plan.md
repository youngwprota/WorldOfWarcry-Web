# Гача-предметы: перчатки, кольцо, амулет и предмет класса
Ветка: feat/gacha-gear · Статус: утверждён

## Цель
Из Горнила падают только перчатки, кольца, амулеты и предметы класса (щит / питомец / сфера), у каждого
своя роль. Концепт каждого предмета — в concept.md. Оружие и броня тела — только с мобов.

## Решения
- Перчатки, кольца, амулеты — по 3 вида, без класса; цифры-заглушки в config, баланс потом — так просили.
- Перчатки выходят из комплектов класса; вид на модели и иконка — перчатки комплекта того, кто надел (арт уже
  есть для всех классов и качеств). Старые `*_arms` в сейве → Рукавицы силы того же качества. (допущение)
- Новые статы: `haste` (скорость атаки, %) у перчаток и `leech` (вампиризм, % урона в HP) у кольца. (допущение)
- Кольцо/амулет одного качества выглядят одинаково (модели и PNG по качеству есть); тип — значок стата в углу ячейки.
- Питомец становится предметом (`kind: 'pet'`) с качеством: урон × RARITY.mult, размер чуть растёт. Сейв
  `pet` → предмет во втором слоте охотника. Модели уже в проекте: wild_direwolf, wild_bear, wild_lion, undead_boar.
- Манеры питомцев: медведь — удар по всем рядом (`cleave`), лев — прыжок издалека (`pounce`). Остальные
  отличаются темпом и типом урона.
- Щиты: все три снова в `CLASSES.warrior.off`. Сферы остаются «одна сфера — одно качество»; в гаче тир даёт
  сферу своего качества: обычный — Ярость, редкий — Ветер и Бодрость, эпический — Оберег. Удача и Демон в гачу
  не попадают (легендарный тир = баннер). (допущение)
- Пул крутки: случайный слот (перчатки / кольцо / амулет / предмет класса любого класса), потом вид. (допущение)
- Баннер: «Кольцо Короля-лича» — легендарное Кольцо крови с именем вместо молота. (допущение)
- Иконки питомцев — рендер GLB через `tools/blender/icon_render.py` + `icon_shrink.py`.
