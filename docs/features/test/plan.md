# Чёрный экран (тест)
Ветка: feat/test · Статус: готово к проверке

## Цель
Тестовая ветка: index.html показывает только чёрный экран, игра не грузится.

## Решения
- Меняем только index.html: body без разметки и без `<script src="/src/main.ts">` — самый быстрый путь, игра не стартует вовсе.
- Код в src/ не трогаем — tsc и сборка проходят как раньше, откат = вернуть один файл.
- viewer.html не трогаем (допущение).
- Ветку в main не мержим — иначе чёрный экран уедет на Pages (допущение).
