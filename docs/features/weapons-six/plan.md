# Система оружия по доске: 4 типа × 6 редкостей, броня 6 слотов × 6 редкостей
Ветка: feat/weapons-six · Статус: утверждён (правка по карточке Леши «Система оружий», ветка origin/board)

## Цель
Только типы из карточки: меч, топор, молот, древковое — 24 именных оружия (тип × редкость), две руки остаются.
Броня: вещь на слот × редкость (36), стат — защита. Добиваний нет, серия из 3 ударов — только у древкового.

## Решения
- Типы (карточка): **меч** — урон 1, скорость средняя (1,15), без сплеша (только цель), дальность средняя 2,3;
  **топор** — урон ×1,15, скорость 1,0, сплеш 30° перед собой, 2,3 м; **молот** — урон ×1,6, скорость 0,7, сплеш
  90°, 2,3 м, свойство типа — сильное расталкивание (оглушение убрать, допущение); **древковое** — урон ×0,9,
  скорость 0,8, дальность 3,2; серия: 1-й и 2-й удар по цели, 3-й — прокрут 360° (×1, допущение).
  Серия — как старое комбо: удары попадают и без паузы, иначе сначала (допущение).
- Кинжалы, жнец, щит удаляются (пользователь: «только указанные типы»). Две руки остаются (пользователь), любые 2 из 4;
  пары с мечом — топор (% HP) и молот (без отброса, сильнее к центру), у древкового пары нет (допущение).
- Добивания Вихрь/Раскол/Землетрясение убираем (пользователь); COMBOS → только серия древкового, точки комбо — только у него.
- Имя = names[редкость] у WeaponDef/ArmorDef, одно для обеих фракций (допущение); имя гачи (Item.name) важнее,
  копии сливаются как раньше. Дроп: Тень — редкий топор, Смерть — эпическое древковое (допущение).
- Древковое: модель nagamaki.fbx из истории (`git show 222e6e1^:...`) + старый хват, одна на все редкости (допущение).
- Броня: 6 defs по слотам (шлем, нагрудник, перчатки, поножи, кольцо, амулет) × 6 редкостей = 36. Только защита,
  бонусы HP/реген/урон/скорость убираем — в карточке статы брони «не относятся к статам перса» (допущение).
  Вид по редкости: 0–1 стражник/рубака, 2–3 рыцарь/громила, 4–5 паладин/вождь (допущение).
- Сейвы (items.normalizeItem): dagger/hidden_blade → меч, reaper/scythe/nagamaki → древковое, shield/pan → молот;
  старая броня guard_head/ring_power/… → вещь своего слота той же редкости и уровня.
