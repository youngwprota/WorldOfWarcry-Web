# Шесть оружий вместо десяти: меньше, но качественнее, без дальнего боя
Ветка: feat/weapons-six · Статус: готово к проверке

## Цель
В игре 6 оружий ближнего боя с ясными ролями и понятными парами с мечом; лишние механики и модели вырезаны,
код и баланс проще.

## Решения
- Оставляем 6: **меч** (универсал, цель + «Вихрь»), **топор** (дуга, сильный удар), **молот** (круг, оглушение),
  **кинжалы** (одна цель, стаки), **жнец** (толпа: стягивает и режет), **щит** (танк, контратаки) — каждый со
  своей ролью и уже есть дроп (кинжалы — «Тень», жнец — «Смерть», молот — баннер гачи).
- Убираем 4: **коса** (бросок, бьёт на расстоянии — «дальнее»), **сковорода** (шуточная, пара с ножом и бегством
  мобов), **скрытый клинок** (дублирует кинжалы в роли «одна цель»), **нагамаки** (дублирует меч, 4-й удар
  пары сложный). Стягивание жнеца — не дальний удар (бьёт вблизи), оставляем.
- Упрощаем пары с мечом: остаются кинжалы (ускорение), топор (% текущего HP), щит (провокация), жнец
  (добивание лишних). Молот+меч: только «без отбрасывания, сильнее к центру» — серп и союзники уходят.
- Вырезаем целиком: src/helpers.ts (союзники), src/orbits.ts (коса, мечи-спутники, падающий меч), состояния мобов
  launch/flee, assassinate/lunge/наезд камеры, удары swing 'throw'/'assassin'/'uppercut'; поля WeaponDef
  orbit/ring/assassin/cycle/ahead; модели nagamaki/scythe/pan/hidden_blade/sickle/kitchen_knife (*.fbx, хваты, иконки).
- Старые сейвы: удалённое оружие превращается в близкое по роли с тем же качеством и уровнем — нагамаки → меч,
  коса → жнец, сковорода → молот, клинок → кинжалы (допущение).
- «Качественнее»: у каждого из 6 свой узнаваемый удар (кинжалы — быстрые чередующиеся взмахи и укол, щит — толчок,
  жнец — широкий горизонтальный взмах), подсказка с ролью и бонусом пары; баланс — по `npm run sim` (допущение).
- tools/blender/weapons.py не трогаем — заготовки моделей остаются в скрипте (допущение).
