# Handoff — Предметы класса: рост от уровня и пассивки с эпического
Дописывать после каждого шага. Это переживает автокомпакт.

## Сейчас
Шаг: доработка «сферы любого качества» сделана и проверена в браузере · Дальше: ревью человеком

## Решения по ходу
- Ответы пользователя: пассивки = готовые механики (отражение, cleave, pounce) с гейтом по качеству + новые там,
  где их нет; сферы тоже получают пассивку с эпического, сильнее на более высоком качестве; «уровень» = уровень
  предмета (копии).

- Вместо одной `classItem(it)` три функции в items.ts: `itemGuard`, `itemOrb`, `itemPassive` + `passiveOf(it, def)`, так короче в местах вызова.
- «Золотая жила» → «Щедрость» (двойные сферы стата в `payRewards`): монет в игре нет.
- Жажда лечит в `damageFor` при крите (от рассчитанного урона, а не от фактически нанесённого).
- В симуляторе (simcore) учтены: рост щита, Шипы, Прыжок, Рвать, Похищение жизни; не учтены Удар лапой, Таран, Барьер, Щедрость, Жажда.

- Доработка по просьбе пользователя: сферы больше не фиксированного качества (убраны `WeaponDef.rarity`, `fixedRarity`,
  `GACHA.orbs`), Горнило даёт любую сферу на любом тире. У каждой из 6 сфер одна пассивка с эпического, растёт по
  качеству: новые Неистовство (fury), Второе дыхание (vigor, `ORB_LOW_HP`), Попутный ветер (swift). Базовый бонус
  сферы растёт только от копий (как у щита: качество → пассивка, уровень → база). Старые сейвы хранят своё качество.

## Грабли и что не сработало
- Сравнение в карточке не парсило «−24%» (U+2212) → блок щита подсвечивался зелёным при ухудшении. Исправлено в `cmp` (inventory.ts).
- Проверка в браузере: FPS вкладки низкий (0,5 с игры за 3,5 с), бой гонял вручную через `game.update(1/30)` в цикле; в лагере мобы не дерутся — `debugTeleport('forest')`.
- Удаление `reflect`/`cleave`/`pounce.mult` из конфига ломает типы до правки всех мест вызова, поэтому шаги 1–6 ушли одним коммитом.

## Важный контекст
- Предметы класса: shield_spiked (воин), orb_* (маг, у каждой одно качество: fury 0, vigor 1, swift 2, ward 3,
  fortune 4, demon 5), питомцы boar/wolf/bear/lion/bone_boar (охотник, WEAPONS[id].pet → PETS).
- Сейчас guard/orb берутся напрямую из WEAPONS[def] в: balance.ts (orbMul, guardMul), game.ts (shieldAnswer ~2331,
  getter orb ~528, pet.def.cleave ~1182), pet.ts (pounce), simcore.ts (~524, ~544).
- Pet уже получает rarity: `new Pet(def, rarity, scene)` (game.ts ~1147).
