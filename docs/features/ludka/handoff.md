## Решения по ходу
- Анимация крутки: вариант «Кузница» (выбор пользователя): 3 удара молота, искры повышают цвет редкости.

- У Item появилось необязательное `name` (уникальное имя оружия с баннера), его возвращает itemName(), normalizeItem его сохраняет.

- Крутка выдаётся сразу при нажатии «Ковать» (game.lootItem теперь публичный и возвращает, куда лёг предмет), анимация только раскрывает результат: закрыть окно посреди анимации — предмет не теряется.
- Ступени редкости по ударам не убывают: s1 ∈ {0,1}, s2 ≤ 2, s3 = итог. При редкости ≥ эпической перед 3-м ударом пауза длиннее.

- Пользователь отверг 2D-кузницу: нужна 3D-сцена удара молота с красивыми эффектами. Решили так: Blender скриптом без UI (не MCP), готовые anvil_big и hammer_human_paladin плюс свои пропсы из Blender.

## Грабли и что не сработало

- Молот: точка вращения на конце рукояти (transform-origin 18% 84%), поднят -45°, удар 66°, .g-hammer top -78px — так головка ложится на заготовку.
- Браузер агента: вкладка часто в состоянии `hidden`, и rAF стоит. Анимацию так не проверить; позы проверял клоном #g-hammer со статичным transform.

- Для теста в скрытой вкладке: подменить requestAnimationFrame/cancelAnimationFrame на setTimeout/clearTimeout, CSS-анимации доводить через document.getAnimations().finish(). Легендарку форсировать подменой Math.random на время клика по #g-pull, ролл — через `await import('/src/gacha.ts')`.
