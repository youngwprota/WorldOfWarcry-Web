# Лудка: окно крутки «Горнило судьбы»
Ветка: feat/ludka · Статус: утверждён

## Цель
Окно крутки в духе гачи Genshin: баннер с главным легендарным оружием, кнопка «Ковать», анимация
кузницы, где редкость видно по цвету искр. Крутка редкая, но выпадают сильные вещи. Выпавший предмет попадает в сумку.

## Решения
- Анимация «Кузница» (выбор пользователя): заготовка на наковальне, 3 удара молота. После каждого удара
  искры могут стать цветом выше (серый → синий → фиолетовый → оранжевый, цвета из `RARITY`). Результат известен заранее,
  удары лишь раскрывают его по ступеням: легендарка может «прорваться» только на 3-м ударе. На финале вспышка цвета редкости,
  из огня поднимается предмет, затем карточка.
- Анимация на DOM + CSS (keyframes) и частицы искр на `<canvas>` 2D в окне. Three.js не нужен, на телефоне дёшево.
  Тап по экрану во время анимации проматывает её к результату.
- Баннер: крупная иконка легендарного оружия, его имя, статы и подпись «Шанс повышен». Данные в `GACHA.banner`
  (src/config.ts): существующий `def` из `WEAPONS` + rarity 3 + собственное имя (допущение: «Молот Короля-лича»).
- Шансы и гарант в `GACHA` (src/config.ts): обычное 70%, редкое 22%, эпическое 7,4%, легендарное 0,6%.
  Гарант: легендарка на 60-й крутке без легендарки. Легендарка на баннере = главное оружие. (допущение, числа крутим потом)
- Счётчик гаранта хранится в сейве (`save.ts`, поле `gachaPity`, по умолчанию 0).
- Валюта пока заглушка: крутка бесплатна, в окне показан счётчик «до гаранта». (допущение)
- Предмет создаётся через `makeItem`, уровень = текущий уровень зоны героя. При полной сумке срабатывает то же правило, что
  при дропе (разбор на золото). (допущение)
- Вход: кнопка «Горнило» в HUD рядом с «Герой/Сумка» и клавиша G. Esc закрывает окно. Пока окно открыто, игра на паузе.
- Только x1 крутка, без x10. (допущение)

## Проверка
- `npm run build` без ошибок
- в браузере (npm run dev): G или кнопка «Горнило» открывает баннер. «Ковать» запускает 3 удара, искры меняют цвет,
  в конце предмет и карточка, в сумке новый предмет. Через дебаг/консоль проверить, что на 60-й крутке выпадает легендарка
  и что тап проматывает анимацию.
- на телефоне: окно влезает в портрет, тапы работают, анимация плавная
