# Фикс UI на телефонах
Ветка: fix/mobile-ui · Статус: готово к проверке

## Цель
Если открыть сайт с телефона, HUD, окна и шторки не съезжают, не налезают друг на друга и не выходят за экран
на любом телефоне в портрете. Адресная строка браузера тоже ничего не ломает.

## Решения
- Сначала диагностика: смотрим вёрстку в браузере на нескольких размерах экрана, найденное записываем в handoff. Симптом «плывёт» описан
  без деталей, поэтому чиним то, что реально видно.
- Вероятные причины, судя по коду: (1) вся вёрстка в фиксированных px и подогнана под экран ≈390×844
  (style.css:385+). На экранах ниже или уже (360×640, видимая область Safari ≈390×660) блоки налезают:
  например, `#skills` стоит на bottom 318px, у `#stats` шрифт 26px. (2) `#app` считает ширину через `100vh`. На
  мобильных это высота без адресной строки, а не видимая высота. (3) Нет `-webkit-text-size-adjust`, нет
  `position: fixed` на body, поэтому на iOS страница может прокручиваться и подпрыгивать.
- Основной фикс — масштаб интерфейса. В resize считаем `s = min(1, w / UI_BASE.w, h / UI_BASE.h)` и задаём `--ui`
  на `#app`. `#hud`, `#modal`, `#dialogue` и `.ad-overlay` получают размер 100%/s и `transform: scale(s)` от
  левого верхнего угла. Вёрстка остаётся в px и не переписывается. На десктопе s = 1, там ничего не меняется.
- Базовый размер `UI_BASE = { w: 390, h: 720 }` лежит в config.ts. Высота 720, а не 844, чтобы на обычном телефоне в браузере
  UI не уменьшался (допущение, подбираем на шаге 1).
- Элементы с экранными координатами внутри `#hud`: `#edge-arrow` (ui.ts:496), `.pro-arrow` (prologue.ts:689),
  `#bigmap` (mapview.ts:54, берёт hud.clientWidth, это уже виртуальные px, проверить). Им делим px на s.
  Метки над мобами (`#labels`) не масштабируем: они в мировых координатах.
- `100vh` → `100dvh` с фолбэком. На body ставим `position: fixed; inset: 0` и `-webkit-text-size-adjust: 100%`.
- Ландшафт на телефоне: оверлей «Поверни телефон» (только CSS, `orientation: landscape` и малая высота)
  (допущение: игра рассчитана только на портрет).

## Проверка
- `npm run build` без ошибок
- в браузере (npm run dev) на тех же размерах, что на шаге 1: HUD не налезает, шторки сумки, героя и талантов
  влезают и прокручиваются, стрелка к цели стоит у края экрана, большая карта открывается по центру, пролог и
  диалог читаются. На десктопе вид как раньше.
- на телефоне по LAN-адресу: прокрутка страницы не появляется, при скрытии и появлении адресной строки UI не прыгает,
  джойстик и кнопки работают, поворот в ландшафт показывает оверлей.
