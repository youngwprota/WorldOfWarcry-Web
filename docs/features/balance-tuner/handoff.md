## Решения по ходу
- Шаг 6: весь tune() идёт в одном воркере (job 'tune'; пробы босса тяжёлые — не на странице), прогоны — во вложенных воркерах (job 'run'), лог строками (msg 'log'). src/tunetab.ts получает от страницы ctx (esc, chart, runJob, sets) — без импорта balancepage (это вход). Запись — POST /__tune-write, плагин в vite.config.ts (apply: serve). Подбор стартует с правок вкладки «Конфиг».
- Шаг 5: writeTuned в src/tunedblock.ts (без импортов — его грузит vite.config.ts): блок <tuned> сливается — старые строки остаются, новые заменяют, сортировка по пути. CLI --write пишет src/config.ts из корня. HP босса считается от probeBoss().hp (поле с ZONE_TIER и напарником), а не от MobDef.hp.
- Шаг 4: ручки — ZONE_SCALE[zone] (hp/dmg по рангам, reward, token) в config.ts, применяют game.ts addMob и sim foeOf/rewardOf; боссы — MOBS[id].hp/dmg. Круг локации: прогон до tProbe (stopTime → чекпойнт 'time') → HP мобов (демпф ^0.6) → HP босса = dps×бой (probeBoss) → урон бисекцией до 50% → проверка stopAt. Минута — regula falsi по tProbe; берётся лучший круг по сумме промахов. Все круги от фиксированных чекпойнтов прошлого босса.
- Шаг 3: tools/pool.ts — runPool(job) по worker_threads (новый поток на часть прогонов, свой конфиг с sets); бандл сам себе воркер (poolWorker()). Типы node — tools/node-shim.d.ts (нет @types/node), tsconfig include расширен.
- Шаг 2: simulateFrom(opts, RunCtl[]) — from/keep/stopAt; Checkpoint.data = structuredClone({h, units, out, t, rs, gates, spent}). Чекпойнт снимается после лута и респауна на первом убийстве босса.
- Шаг 1: FightRec.zone/rank (topRank пачки, static отдельно), SimSummary.fightDur (медиана выигранных боёв), RunOut.gachaShare по боссу (Hero.gacha — Set предметов из pull; lootItem возвращает оставленный предмет). Цели по умолчанию в src/tunetargets.ts (допущение: босс каждые 15 мин после леса).
- Ответы пользователя: менять можно всё; сила = общая мощь (might); подобранное — в config.ts отдельным коммитом.
- Ветка от feat/balance-sync (не слита в main): тюнер стоит на её симе (дальние земли, пачки).

## Грабли и что не сработало
- Шаг 5: после подбора леса герой приходит на кладбище на ~20 мин раньше и слабее — элитки кладбища (там нет обычных мобов) он не бьёт, нет боёв → нет круток → гача 0%. Решение: ранг, который в локации есть (виден в исходном прогоне), но не побеждён до минуты — HP и урон ×0.6 за круг. Королева: бой 205 с вместо 110 — забыт ZONE_TIER в HP босса (исправлено).
- Шаг 4: лес шумный — минута Атамана прыгает 6–13 мин между кругами (урон босса бисекцией по одному герою). За 8 кругов лучший 9.0 мин / бой 97 с; ~13 с на круг. По умолчанию --iters 6. Элитки/мини леса до убийства Атамана бот не бьёт — их длины не судятся.
- Шаг 3: 10 прогонов до 90 мин — 30 с (было ~160 с), результаты те же.
- Возобновление не бит-в-бит: Смерть 2527.6 против 2528.8 с с нуля (кэш оценок сбрасывается) — для подбора неважно.
- Сейчас (token normal 0.05): Атаман 32/10, Смерть 41/30, Королева 81/45; бои мобов кладбища и дальше 0–5 с — герой перерос мобов (HP мобов надо поднимать сильно).
